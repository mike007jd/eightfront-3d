基地射击与目标标记

基地普通房间需要横移对列：站／趴／跳改变枪线，鼠标不能跨列代替姿态。先松开左右移动与 SHIFT，再按下键趴射；高位核心需松开下键后跳射。

小圆准星预览当前枪口中心线的落点，不代表散射的每颗弹丸。实线目标可攻击，闭合标记表示暂受保护；装甲条减少也是有效命中。核心全毁后，任一玩家向前进入下一室。

双人与手柄

P2：方向键移动，/ 射击，. 跳跃，, 换枪，' 手雷。也可使用小键盘 1 / 2 / 0 / 3。无友伤，一人出局后队友继续。

手柄：方向键或左摇杆移动，A 跳跃，X / RT 射击，Y 换枪，RB 手雷，Start 暂停。菜单中方向键选择，A 确认，B 返回。

进阶操作与复古模式

↓ + 跳跃：穿过单向平台。现代模式可长按射击、短按小跳，P1 可用鼠标瞄准；基地普通房间仍受站位与姿态限制。复古模式下 R / S / F 点按，M / L 长按；固定跳高、八向瞄准，不是完整 NES 仿真。

DESKTOP EDITION

使用键盘或手柄游玩

此版本没有触屏战斗操作。请在电脑横屏下打开，或连接键盘、手柄后使用横屏。
