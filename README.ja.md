# Eight Fronts

非公式の Three.js トリビュートゲーム。全 8 ステージ、ローカル 2 人プレイ、モダン／レトロの操作方式に対応。アセットはすべてプロシージャル生成のオリジナルで、実行時リソースは全部埋め込み済み、CDN へのリクエストはありません。

## 実行

```bash
npm run build
```

`vendor/three.bundle.js` と `dist/index.html` が生成されます（どちらも生成物で、リポジトリには含めません）。デスクトップブラウザで `dist/index.html` を直接開くか、`npm run serve` を実行してターミナルに表示されるローカルアドレスを開いてください。Node.js 20 以降が必要で、npm 依存パッケージのインストールは不要です。

## 操作

P1：WASD 移動、J／マウスで射撃、SPACE／K でジャンプ、Q で武器切替、E／G で手榴弾、SHIFT でその場で照準、ESC でポーズ。P2：矢印キー移動、/ で射撃、. でジャンプ、, で武器切替、' で手榴弾。テンキーにも対応しています。

基地の通常ルームでは、横移動で目標の列に位置を合わせます。低い目標は移動キーと SHIFT を先に離してから下キーを押し続けて伏せ撃ち、高い目標はジャンプ撃ちが必要です。基地での姿勢切替はマウスでは代用できません。コアをすべて破壊したら前進して次のルームへ進みます。設定の状況ガイドは有効のままなので、原作を知らなくても始められます。
