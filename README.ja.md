# Eight Fronts

![Eight Fronts タイトル画面](docs/title.jpg)

8 ビット時代のラン＆ガン名作へ捧げる非公式の Three.js トリビュート。全 8 ステージ、ローカル 2 人協力プレイ、モダン／レトロの操作方式に対応。アセットはすべてプロシージャル生成のオリジナルで、実行時リソースは全部埋め込み済み、CDN へのリクエストはありません。HTML ファイル 1 つで完全オフライン動作します。

- **3 種類のステージ構成**——横スクロールの戦線、奥へ進む基地ルーム、垂直に登る滝。
- **8 体のボス**。コアには露出／閉鎖のフェーズがあり、目標横のマーカーが「今どこを撃てるか」を示します。
- **5 種類の武器**（ライフル、マシンガン、スプレッド、レーザー、火炎）と手榴弾。拾った武器は予備として 1 つ保持。
- **ローカル協力プレイ**——キーボード 1 台またはゲームパッド 2 台。同士討ちなし、倒れたプレイヤーは次の残機で復帰。
- **モダン／レトロのルール**——マウス照準・長押し連射・小ジャンプ、またはジャンプ高さ固定・8 方向照準・連打射撃。
- **戦闘中のガイド**——基地ルームとボスの状況ヒント。常時表示やオフに切り替え可能。
- **UI は English、简体中文、日本語** に対応。メインメニューで切り替え。
- Three.js r179 上のオリジナル前方 HDR パイプライン：GPU スキニングの兵士、SSAO、影を考慮したフォグ、ブルーム。画質プリセットは 3 段階。

## 実行

```bash
npm run build
```

`vendor/three.bundle.js` と `dist/index.html` が生成されます（どちらも生成物で、リポジトリには含めません）。デスクトップブラウザで `dist/index.html` を直接開くか、`npm run serve` を実行してターミナルに表示されるローカルアドレスを開いてください。Node.js 20 以降が必要で、npm 依存パッケージのインストールは不要です。メインメニューの **オフライン版を保存** ボタンで、同じ単一ファイルビルドをゲーム内から書き出せます。

デスクトップ専用：キーボード、マウス、またはゲームパッド。タッチ専用デバイスではゲームの代わりに案内が表示されます。

## 操作

| 操作 | P1 | P2 | ゲームパッド |
|---|---|---|---|
| 移動／照準／しゃがみ | W A S D | 矢印キー | 十字キーまたは左スティック |
| 射撃 | J またはマウス左 | /（テンキー 1） | X または RT |
| ジャンプ | SPACE または K | .（テンキー 2） | A |
| 武器切替 | Q | ,（テンキー 0） | Y |
| 手榴弾 | E または G | '（テンキー 3） | RB |
| その場で照準 | 左 SHIFT | 右 SHIFT | LB |
| ポーズ | ESC | ESC | Start |

1 人プレイでは矢印キー、Z（射撃）、X（ジャンプ）も使えます。↓ + ジャンプで一方通行の足場を降ります。モダンルールでは P1 がマウスか右スティックで照準可能。レトロルールでは自由照準が無効になります。

基地の通常ルームでは、横移動で目標の列に位置を合わせます。低い目標は移動キーと SHIFT を先に離してから下キーを押し続けて伏せ撃ち、高い目標はジャンプ撃ちが必要です。基地での姿勢切替はマウスでは代用できません。コアをすべて破壊したら前進して次のルームへ進みます。

## オプション

- **部隊**——1 人またはローカル 2 人。**言語**——English、简体中文、日本語。
- **キャンペーン設定**——モダン／レトロ操作。アーケード（アーマー 3、チェックポイントで回復）／クラシック（一撃ダウン）難易度。
- **設定**——画質プリセット（軽量／高画質／シネマティック）、レンダリング解像度 50–125 %、画面の揺れと閃光の抑制、ガイドレベル（状況／強化／オフ）、習得済み操作のリセット。
- **診断**——F3 でフレーム統計、F8 で UI 非表示、生のフレームタイムを JSON で書き出し。

## プロジェクト構成

`scripts/build.mjs` が連結するプレーンなブラウザスクリプトのみ。バンドラーやフレームワークは使いません。

| ファイル | 役割 |
|---|---|
| `src/shell.html` | メニュー、HUD、ダイアログのマークアップと CSS |
| `src/app.js` | 入力、メニュー、設定、セーブ、HUD 同期 |
| `src/game.js` | シミュレーション：プレイヤー、敵、ボス、ルーム、チェックポイント |
| `src/stages.js` | 8 ステージの定義、基地ルームの遭遇、武器 |
| `src/guidance.js`、`src/guidance-ui.js` | 目標状態モデルと画面上のヒント |
| `src/i18n.js` | en / zh / ja の UI 文言 |
| `src/renderer-three.js`、`src/shaders.js` | Three.js r179 上の前方 HDR パイプライン |
| `src/characters.js`、`src/geometry.js`、`src/*-assets.js` | プロシージャルなリグ、メッシュ、環境プロップ |
| `src/stage-previews.js` | 埋め込みのステージサムネイル（ゲーム自身のフレームを切り出したもの） |
